# Security policy

RepoQuest is a client-side application that reads public GitHub data without storing source contents on a server.

Please do not place access tokens, private-repository contents, or personal data in a public issue. For a vulnerability that should not be disclosed publicly, use GitHub's **Security → Advisories → Report a vulnerability** flow when it is available for this repository. Otherwise, contact the repository owner through the public profile before sharing reproduction details.

Include the affected URL or version, impact, reproduction steps, and any suggested mitigation. You should receive an acknowledgement before public disclosure.
